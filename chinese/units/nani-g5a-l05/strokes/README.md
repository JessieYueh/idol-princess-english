# Character stroke reference

The 18 JSON files are unchanged copies from https://github.com/chanind/hanzi-writer-data/tree/master/data, derived from Make Me a Hanzi / Arphic font data. The applicable Arphic Public License is included in ARPHICPL.TXT.

The application compares stroke counts and approximate geometry. It does not enforce stroke order or certify conformance to Taiwan Ministry of Education stroke order. The displayed font is separately provided by the Ministry of Education, Republic of China (Taiwan), under CC BY-ND 3.0 TW. A byte-identical mirror of the official 5.1 TTF is used as a web font; glyphs are not modified.
