# 南一五上國語期中總複習

獨立新增單元：`index.html`（總複習）、`mistakes.html`（錯題）、`answers.html`（對照及列印），三頁共用資料與手寫程式。原有單元未改動。

## 照片對照

照片1、2：期中平時考正反面（字音字形75題、短語3題、造句4題）。照片3：第一課（字音字形50題、短語3題、造句10題）。照片4至8：第二至六課（96、78、77、71、78題）。保留來源及題號；不公開原照片、姓名、班級及座號。

合計545題，均已補齊。依補拍照片確認：照片3第16題為「擦痕（ㄘㄚ ㄏㄣˊ，依家長確認）」；照片8第4題為「棋盤（ㄑㄧˊ ㄆㄢˊ）腳」，指定填寫「棋盤」。長短語與造句的答案是自編示例，並非唯一正解。照片延伸成語依原卷保留。

## 錯題與狀態

初始錯題依可辨識的圈選和紅筆訂正整理，允許手動加入及移除；初始標記只是待加強候選。`localStorage`僅保存此裝置的錯題ID，不保存筆跡或孩子文字答案。重新整理時筆跡、文字與本輪核對標記均清空。支援Touch.identifier手指路徑，以及Pencil／滑鼠Pointer Events；離開畫布斷筆，抬筆不添加末點；清除可復原。
